# 🛒 E-Commerce Website – UI/UX Case Study

## Project Overview
A UI/UX design project focused on improving product discovery and checkout experience in an e-commerce platform.

## Problem Statement
Users struggled with product search, filtering, and completing checkout smoothly.

## Target Users
- Online shoppers
- Mobile-first users
- Deal seekers

## User Goals
- Find products quickly
- Compare options easily
- Checkout without friction

## UX Process
- User journey mapping
- Wireframing
- UI design
- Usability improvements

## Design Solution
- Clean product listing layouts
- Improved filters and search
- Simplified cart and checkout flow
- Mobile-first design

## Tools Used
- Figma
- FigJam
